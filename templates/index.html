Welcome to House Price Prediction

Data Analysis

The Ames Housing dataset contains 1,460 rows and 80 columns. Extensive Exploratory Data Analysis (EDA) was performed to handle missing values, encode categorical variables, and remove outliers.

Feature Importance

The Random Forest model identified the following features as having the highest impact on house prices:

  1. Overall Quality: The material and finish of the house.
  2. Above Grade Living Area: Total square footage of living area above ground.
  3. Total Basement Area: Total square feet of basement area.
  4. Garage Cars: Size of garage in car capacity.

Prediction Insights

The model has a high confidence rate (88% R²) for standard residential homes. However, predictions for luxury estates or highly irregular properties may have a larger margin of error due to limited training data in those ranges.

About This Project

Built using Scikit-Learn, Flask, and Tailwind CSS. This project serves as an end-to-end demonstration of a Machine Learning pipeline, from data preprocessing to model deployment.
